主要项目

Snap Desk — 免费开源的 Windows 截图与录屏工具

Snap Desk（也写作 SnapDesk）支持区域截图、滚动截图（长截图）、图片标注、桌面贴图、MP4/GIF 录屏、OCR 文字识别、文本翻译和剪贴板历史管理。基于 Tauri 2、Rust 与 Vue 3，GPL-3.0 开源。

  • 截图
  • 滚动截图
  • 录屏
  • OCR
  • 贴图
  • 剪贴板
  • Windows x64
